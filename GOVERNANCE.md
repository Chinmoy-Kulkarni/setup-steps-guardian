# Governance

SetupStepsGuardian is currently maintained by
[@Chinmoy-Kulkarni](https://github.com/Chinmoy-Kulkarni).

## Decisions

- Routine fixes are decided through pull-request review.
- User-visible policy changes require tests, documentation, and evidence from current GitHub
  documentation or reproducible public fixtures.
- Larger scope changes should begin in an issue or Discussion so tradeoffs are public.
- The maintainer has final responsibility for releases, security responses, repository settings,
  and project scope.

## Releases

The project follows Semantic Versioning. Stable finding codes are part of the public interface.
Patch releases may correct false positives, documentation alignment, and compatible detection
behavior. Breaking policy or output changes require a major release.

## Maintainer growth

There is no fixed path or timeline for adding maintainers. Sustained, high-quality contributions
and sound judgment about compatibility, privacy, and false positives are prerequisites. Any change
to maintainer status will be recorded publicly.

## Project direction

The open-source validator is the current priority. A hosted service or paid plan is not a project
commitment and will not take priority without demonstrated public demand.
